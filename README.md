# Cognistack
Machine Learning Model: Training five dummy Random Forest models for the OCEAN traits.

Backend Server: A Flask API to serve the application and handle analysis requests.

Frontend Application: A complete React.js application written in JSX, embedded directly into the HTML. It includes animations and communicates with the backend.

To run this code, you only need to have Python and the required libraries installed.

## Instructions to Run
Save the code: Save the entire block of code below as a single file named cognistack_app.py.

Install libraries: Open your terminal or command prompt and install the necessary Python packages.

Bash

pip install Flask scikit-learn pandas
Run the script: Execute the file from your terminal.

Bash

python cognistack_app.py
Open in browser: Open your web browser and navigate to http://127.0.0.1:5000. You will see the fully interactive CogniStack application.
